# Дизайн склада (с 2026-11-12)

Стиль — как у современных WMS: светлый серо-голубой фон, белые карточки со скруглением и мягкой
тенью, индиго-акцент. Есть тёмная тема (кнопка в меню, выбор запоминается на устройстве).

## Правила
- **Расположение кнопок на страницах не меняется** при правках внешнего вида.
- **Таблицы не трогаем**: их цвета, линии, шрифты и ускорения прокрутки — на прежних переменных
  (`--line`, `--line-strong`, `--th-bg`, `--group-bg`, `--tbl-*`, `--card`). Новый вид — только на `--ui-*`.
- Логотип — текстом: «BLAGO» цветом текста, «склад» — синим, без значка-квадрата.
- Режим проверки сканов — жёлтый кружок у названия (подсказка при наведении), а не полоса на всю ширину.
- Компьютер (от 1024 px): меню слева с иконками (`aside.side`), внизу — сотрудник, тема, «Выйти».
- Телефон и планшет: шапка и лента меню сверху (`header.top`, `nav.menu`), выбранный пункт — индиго-«пилюля».
- Подписей под вкладками и плитками нет — только названия (решение владельца 2026-11-12).
- Иконки меню — контурные 24×24 в `app/templates/_icons.html`, по адресу пункта. Новый пункт меню — добавить иконку.

## Переменные (`app/static/app.css`, блок «Новый вид»)
| Переменная | Светлая | Тёмная | Для чего |
|---|---|---|---|
| `--ui-bg` | #f4f6fb | #0e1220 | фон страницы |
| `--ui-card` | #ffffff | #161b2c | карточки, шапка, меню |
| `--ui-text` / `--ui-muted` | #1b2037 / #6b7285 | #e8ebf5 / #98a1b8 | текст / второстепенный |
| `--ui-line` | #e6e9f1 | #252c42 | рамки карточек |
| `--ui-accent` | #4c5fd5 | #7c8cff | кнопки, выбранный пункт, ссылки |
| `--ui-accent-soft` | #eef0fd | #232a4d | фон выбранного пункта, наведение |
| `--ui-radius` / `--ui-radius-sm` | 14px / 10px | | карточки / кнопки и поля |

Цвета статусов (зелёный, красный, жёлтый) — прежние: `--ok`, `--err`, `--warn`.

## Проверка после правок вида
Скриншоты всех страниц всех ролей на телефоне (iPhone 13) и компьютере (1366×860): страница не уезжает
вбок, нет ошибок JS, таблицы выглядят как до правки.
