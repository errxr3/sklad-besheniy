# Запуск склада

Адрес системы: **https://89-169-45-92.sslip.io**. Сайт работает в браузере телефона или компьютера,
ставить ничего не нужно.

План на три шага: подготовка (администратор, 1–2 часа), ввод остатков (кладовщицы, полдня),
первый рабочий день. Инструкция по ролям для сотрудников лежит в `docs/инструкция.md`.

---

## Шаг 1. Подготовка (администратор)

### 1.1. Смените свой PIN
Войдите как **«Администратор»** с PIN **1234**. Откройте **Администратор → Сотрудники**, найдите
себя и нажмите **«Сбросить PIN»** с новым PIN из 4–6 цифр. Пока стоит 1234, войти под админом
может любой, кто знает адрес.

### 1.2. Проверьте площадки
**Администратор → Площадки.** Площадок две:
- **Учительская** делает артикулы, которые начинаются на `Ambient`;
- **Коминтерна** делает `Zerkalo` и `Alum`.

Если распределение другое, поправьте поле с началами названий через запятую. От этого поля
зависит список артикулов, который начальник смены видит при постановке задач.

### 1.3. Проверьте артикулы
**Администратор → Артикулы.** В базе 296 артикулов из TOP.xlsx. Появился новый артикул или
поменялся порядок, загрузите свежий TOP.xlsx здесь же. Ненужные артикулы отключите.

### 1.4. Заведите сотрудников
**Администратор → Сотрудники → Добавить.** Для каждого человека укажите:

| Поле | Что ставить |
|------|-------------|
| Имя | Как его зовут на складе. Это имя печатается на этикетках |
| Роль | Сборщик, Грузчик, Кладовщица, Возвраты, Начальник смены или Администратор |
| PIN | 4–6 цифр. Человек будет набирать его при входе |
| Площадка | Для сборщика и кладовщицы обязательно: там человек работает и туда пишется склад |

Сборщик без площадки при начале смены выбирает её сам и может ошибиться, а в задачах он виден
на обеих площадках. Кладовщица видит задачи только своей площадки.

Начальнику смены площадку ставьте, если он отвечает за одно производство: тогда в задачах он
видит только его и только его сборщиков. Без площадки начальник смены работает с обеими.

PIN раздайте лично, не в общий чат. Если человек 5 раз ошибётся, вход закроется на 15 минут.
Забытый PIN вы сбрасываете в той же карточке.

### 1.5. Настройте принтер этикеток
1. **Администратор → Параметры**: размер этикетки. По умолчанию 58×40 мм. Поставьте размер
   рулона, который стоит в термопринтере.
2. Подключите термопринтер к компьютеру кладовщицы как обычный принтер.
3. Пробная печать: **Кладовщица → Ввод остатков**, любой артикул, количество **1**. Откроется
   PDF. Печатайте с масштабом **100%** («Фактический размер»), без полей.
4. Отсканируйте напечатанную этикетку сканером в **«Лишние этикетки»**. Зелёный экран значит, что
   штрихкод читается, а пробная этикетка ушла со склада.

Если этикетка печатается мелко или съезжает, проверьте размер бумаги в настройках принтера:
он должен совпадать с размером в «Параметрах».

### 1.6. Проверьте сканеры и телефоны
- Ручной сканер подключите к телефону или компьютеру. На экране скана выберите **«Сканер»**.
  Раскладка клавиатуры не важна: система сама исправит русские буквы.
- На телефоне без сканера выберите **«Камера»** и разрешите браузеру доступ к камере.
- Сохраните адрес сайта на главный экран телефона (в меню браузера «Добавить на главный
  экран»), чтобы сотрудники не искали ссылку.

## Шаг 2. Ввод остатков (кладовщицы)

Система должна знать, что уже лежит на складе. Каждая кладовщица делает это на своей площадке,
до первого рабочего дня. Интернет нужен только для печати и для скана лишних этикеток.

1. Пересчитайте зеркала одного артикула.
2. **Ввод остатков** → артикул, количество с запасом (например, насчитали 37, печатайте 40) →
   **«Напечатать и записать на склад»**. За один раз можно до 300 штук.
3. Наклейте этикетки на зеркала.
4. Лишние этикетки (в примере 3 штуки) отсканируйте в **«Лишние этикетки»**.
5. Переходите к следующему артикулу.

Проверка: начальник смены открывает **Склад → Остатки** и сверяет цифры с пересчётом. Если
где-то не сходится, администратор поправит через **Инвентаризацию**.

Зеркала, которые уходят в отгрузку, должны быть с этикеткой BLAGO. Без неё грузчик не сможет
их отсканировать.

## Шаг 3. Первый рабочий день

### Накануне вечером (начальник смены)
**Задачи** → дата завтра → каждому сборщику артикул и количество. Без задач кладовщице нечего
печатать, а у сборщика не появится кнопка «Собрал всё».

### Утро
| Кто | Что делает |
|-----|------------|
| Кладовщица | **Печать этикеток** → «Сегодня» → **«Напечатать всё: Иван»** по каждому сборщику. Кладёт этикетки в коробку с комплектующими |
| Сборщик | Входит, нажимает **«Начать смену»** |
| Грузчик | Входит, выбирает площадку: Коминтерна или Учительская |
| Начальник смены | Открывает **Табло смены**: видит, кто вышел, а кто нет |

### В течение дня
- **Сборщик** клеит этикетки и по каждой задаче нажимает **«Собрал всё (N шт.)»**, когда
  спускается к интернету. Неиспользованные этикетки отдаёт кладовщице.
- **Кладовщица** сканирует эти этикетки в **«Лишние этикетки»**.
- **Грузчик** выбирает канал (Озон 1, Озон 2, Озон 3, WB, СДЭК, СГТ, КГТ), сканирует зеркала,
  закрывает канал. Пока канал открыт, в таблице отгрузки его зеркала видны серым «+N», в цифры
  они попадают после закрытия.
- **Возвраты** сканируют вернувшиеся зеркала. Зеркалам без этикетки печатают ШК в
  **«Этикетки без ШК»**. Всё встаёт на склад Коминтерна.

### Вечер (начальник смены)
1. **Склад → Отгрузка**: красная плашка значит, что кто-то не закрыл канал. Попросите грузчика
   закрыть. Если забудут, система закроет канал сама в 23:59.
2. Скачайте **XLSX** и разнесите в гугл-таблицу отгрузок, если она ещё нужна.
3. Не доделали задачу — сборщик отдаёт ненаклеенные этикетки кладовщице, она сканирует их в
   **«Лишние этикетки»**. На завтра начальник ставит задачу заново.
4. **Табло смены**: у кого смена осталась открытой, закройте с причиной. В 00:05 система
   закроет забытые смены сама.

## Первая неделя

Первые 5–7 дней начальник смены каждый вечер сверяет **Склад → Остатки** с тем, что лежит на
полках, по 5–10 ходовым артикулам. Расхождение чаще всего значит одно из двух:
- сборщик нажал «Собрал всё», а кладовщица не убрала лишние этикетки (на складе больше, чем
  на полке);
- грузчик отгрузил зеркала, не отсканировав их (на складе больше, чем на полке).

Найти конкретное зеркало и его историю можно в **Найти зеркало** по номеру с этикетки.
Все движения за день видны в **Журнале**.

## Если что-то сломалось

| Что видите | Что делать |
|------------|------------|
| Красный экран «Нет связи, скан НЕ записан» | Дождаться интернета и отсканировать ещё раз. Дважды ничего не запишется |
| Сборщик начал смену не на той площадке | Закончить смену и начать заново. Администратор указывает ему площадку в карточке сотрудника |
| Кладовщица не видит задач | Проверить её площадку и дату («Сегодня» / «Завтра») |
| Этикетка испортилась | Начальник смены: **Найти зеркало** → номер → «Перепечатать этикетку» |
| Сайт не открывается | Администратор открывает **Состояние системы**. Не открывается и оно, пишите разработчику |

Каждую ночь в 03:17 сервер сохраняет копию базы и хранит её 30 дней.
